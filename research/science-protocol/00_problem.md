# Science Protocol: Synthetic Measurement of Scientific Reasoning

## Research Question
Can we build a comprehensive synthetic science measurement protocol that rigorously tests the scientific reasoning ability of intelligent systems (LLMs, PLN-based reasoners, ML tool users) across multiple scientific fields and difficulty levels?

## Scope
- Target systems: LLMs, probabilistic logic reasoners (PLN/MeTTa), agentic systems with ML tool access, hybrid architectures.
- Coverage: >= 4 scientific fields (e.g., physics, chemistry, biology, ecology, astronomy, geoscience), each with synthetic datasets of graded difficulty (>= 3 tiers).
- Task types: hypothesis generation, experimental design, causal inference, evidence integration / belief revision, model fitting, anomaly detection, prediction under intervention.

## Success Metrics
- Protocol covers >= 4 fields with >= 3 difficulty tiers each.
- Ground-truth-scoringable: every task has programmatic, objective scoring.
- Discriminative: tasks separate weak baselines from strong systems.
- Difficulty validated: empirical monotonic performance decline with tier.

## Constraints
- Fully synthetic (generated by code, no licensing issues, infinite regeneration).
- Reproducible: seeds and generators versioned in git.
